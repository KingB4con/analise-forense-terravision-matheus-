# MineVision

Projeto de análise de áreas de mineração e alterações
da topografia terrestre.

## Objetivo

Desenvolver uma aplicação para computador capaz de
organizar dados geográficos, visualizar áreas de
mineração e analisar mudanças na superfície terrestre.

## Tecnologias

- Python 3.12
- Git e GitHub

## Status

Em desenvolvimento.
